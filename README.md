# 📊 Featured Data Analytics Projects

## 🏥 Medical Insurance SQL Analysis

A SQL data analysis project exploring factors associated with medical insurance charges, including:

- Smoking status
- BMI
- Age
- Sex
- Number of children
- Region

The project uses SQL aggregation, conditional analysis, segmentation, and comparative metrics to identify patterns in insurance costs.

### Key Finding

Smokers in the analysed dataset recorded average insurance charges of **32,050.23**, compared with **8,440.66** for non-smokers — approximately **279.71% higher**.

🔗 [View Medical Insurance SQL Analysis](https://github.com/mezidecent-tech/Medical-Insurance-SQL-Analysis)

**Tools:** SQL Server | SSMS | SQL | Git | GitHub
